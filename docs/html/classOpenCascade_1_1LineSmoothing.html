Detailed Description

Smooth all dofs in euler_vector for which smoothing_dofs is set to true. Exceptions are thrown if the points are not located on the Geometry curve. The parameter base_point_id, identifies the 3 dofs associated with the base point, which is the one left untouched. All other points are moved proportionally to their arclength distance from the base point.

void OpenCascade::LineSmoothing::smooth ( bool  maintain_on_original_curve = true)

Perform the actual smoothing.

  • Updates the driving point location based on the euler displacement vector euler_vector.
  • If maintain_on_original_curve is enabled, ensures the curve stays constrained to the original.
  • If maintain_on_original_curve is disabled, we first get all the points on this un-smoothened curve, update it with euler_vector and interpolate it to obtain the curve based on these new points. Since curve is changed, occ_base_t is also updated.
  • Based on the argument, whatever curve we retain/obtain, we create a geometry adaptor of the same, obtain the occ_driving_t driving point curve parameter. Also obtain the total length of the curve using occ_base_t and occ_driving_t.
  • Projects smoothing points onto the new curve using fixed_length_ratios and updates the displacement vector euler_vector accordingly.
Parameters
maintain_on_original_curveboolean flag to decide whether the moving point is projected to the original curve. If this is not the case, then all points are maintained in their current location, a new curve is computed which passes through all current points, and their smoothing is computed according to their original location.

void OpenCascade::LineSmoothing::update_reference ( unsigned int  base_point_id,
unsigned int  driving_point_id 
)

Map degrees of freedom (DoFs) onto support points.

  • First, it converts the Geom_Curve into geometry adaptor BRepAdaptor_Curve to store the curve parameter value of base point in occ_base_t.
  • Compute the reference support points (this is local to this class only).
  • Then we loop over all the nodes, the points for which smoothing_dofs==true (or all point currently lying b/w base and moving point), we store the indices in an increasing order of its distance from base point, in smoothing_list which is a std::map mapping std::pair of parameter value and distance value to the corresponding indices. The distance is calculated using curve parameter values.
  • Calculate the reference length of the curve which will the highest value of curve distance value in smoothing_list.
  • Re-initializes the deal.II Vectors<double> lengths_before_smoothing, lengths_after_smoothing, fixed_length_ratios, and std::vector node_indices. Also updates the node_indices and fixed_length_ratios based on smoothing_list.
