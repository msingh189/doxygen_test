Distribute degrees of freedom which involves allocating memory to store the indices on all entities on which degrees of freedom can be located (e.g., vertices, edges, faces, etc.) and to then enumerate all degrees of freedom. One is for fe and other is for vector_fe.

Initialize and set the size of various dealii::Vector<double> vectors. See the classMembers.md to know more about them.

Next, we fill the coordinates corresponding to each DoF in vector_dh in ref_points, using deal.II DoFTools::map_dofs_to_support_points<dim, spacedim>().

Now, we create our eulerian mapping as mapping = new dealii::MappingQEulerian<2, dealii::Vector<double>, 3>(mapping_degree, vector_dh, map_points). MappingQEulerian class provides a mapping that adds to the location of each cell a displacement field (map_points here). Each cell is thus shifted in space by values given to the mapping through a finite element field.

  • Calculates deal.II Vector<double> surface_nodes and other_nodes. These vectors are needed to treat Dirichlet and Neumann nodes differently. Each component of the first one is zeros if it corresponds to a Dirichlet node, and ones if it corresponds to a Neumann node. The second vector has instead ones entries for Dirichlet nodes, and zeros for Neumann nodes.
  • Reinitialize various std::vector and deal.II Vector<double> like iges_normals, old_iges_normals, iges_mean_curvatures, edges_tangents, edges_length_ratios, and smoothing_curvature_vector. Check classMembers.md to know more about the same.
  • set_up_smoother(): As the name suggest, it initializes both the surface and line smoothers if called first time or updates them if already initialized.
    First we will talk about line smoothing;
    • If called for time, we run initialize_smoother() function, which basically create a std::vector of LineSmoothing class objects stored as line_smoothers. Before creating this class, we store the std::vector of following items:
      • boundary_ids: manifold ids of different hull boundary curves.
      • base_points: contains the deal.II Point<3> of base points of each line smoothing, which remains fixed.
      • moving_points: contains the deal.II Point<3> of moving points of each line smoothing, which as the name suggests is free to move.
      • base_point_ids: index of base_points stored as unsigned int.
      • moving_point_ids: index of moving_points stored as unsigned int.
      • curves: contains the OpenCASCADE Geom_Curve of each curves
      • on_curve_option: contains booleans if curve must be rebuilt at each call of smoothing routine. true for keel smoothings, false for water line smoothings.
      • smoothers_locations: contains OpenCASCADE TopoLoc_Location locations which are needed when current hull configuration is roto-translated.

void NumericalTowingTank::full_mesh_treatment()
{

perform_water_line_nodes_projection();

perform_surface_projection();
vector_constraints.distribute(map_points);
update_support_points();
}

  • perform_line_smoothing(line_smoothers.size()): Performs the actual smoothing of the different curves by updating the map_points (the displacement vector) of points lying on different curves of hull.
    • First a copy of map_points is stored in smoothing_map_points. Then we perform the line smoothing of each 7 curves, using line_smoothers[i].smooth(). Then the copied smoothing_map_points is copied again to map_points.
    • We update the support points and reference points using update_support_points().
    • This line smoothing moved only one nodes of multi-node sets, we loop over all the nodes on all curves to move their twins using vector_double_nodes_set.
  • perform_water_line_nodes_projection(): Projects all the points on the current waterline to the actual waterlines and also calculates the mean curvature & normal vector at these points.
    • We start with updating the support points and reference points using update_support_points().
    • Then we project all point on the left and right waterline (except bow and stern nodes) to boat_water_line_right/boat_water_line_left and also update the normals and mean curvature at these curve points.
    • Using these projected nodes, we update their twins also.
  • perform_smoothing(...): Performs the surface smoothing of all the points of free surface and hull surface except on the waterline, keel and transom curves. It takes two arguments bool full_treatment and double blend_factor.
    • We loop over all the nodes except the nodes which are present on waterlines, keel or transom, and update the smoothing_curvature_vector entries. It is calculated as -iges_normals[i][]*(iges_mean_curvatures[i]) for any node i.
    • We make a copy of map_points and store in smoothing_map_points. Then we perform the surface smoothing by surface_smoother->smooth(). Look at the class SurfaceSmoother to know more.
    • If full_treatment==false, we are on the free surface and only horizontal components of map_points must be changed according to the smoothing (the third one will be changed according to the free surface differential equation). Otherwise, all three components are updated.
  • perform_surface_projection(): Projects the current points on the hull's surface on the actual hull's surface along with updating the mean curvature and normal vectors.
    • We first update the vector of mesh normals at node, then we update the support points and reference points using update_support_points().
    • Then we perform the projections using AxisProjection object (same used in perform_water_line_nodes_projection()) as mentioned in above description.
  • vector_constraints.distribute(map_points): After calculating all the displacement of all nodes possible in map_points, we set all constrained dofs to values so that constraints are satisfied using distribute() functionality of AffineConstraints.
  • At end one last time, support points and reference points are updated using update_support_points().
