Detailed Description

template<int dim>
class Driver< dim >

This class is responsible for running the simulation. Here, all the constructors of fundamental classes are called. All the inputs required from input parameter file (.prm) of corresponding classes are also declared and processed here.

Template Parameters
dimSpatial dimension (2D/3D)

Construct a new Driver object.

  • Creates NumericalTowingTank, BEMFMA, BEMProblem, FreeSurface class objects and dealii::ParameterHandler object for handling the parameters from input file.
  • Declare the parameters using DeclareParameters(). Then input (.prm) file is read.
  • Store the parameters read using DeclareParameters() into corresponding class attributes using ParseParameters().
  • A new '_used.prm' file is also created where all the parameters considered for simulation is written.
