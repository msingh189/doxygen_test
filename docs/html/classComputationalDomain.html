Detailed Description

template<int dim>
class ComputationalDomain< dim >

This class is responsible for basic deal.II classes setup needed by the program: deal.II Triangulation, FiniteElement and DoFHandler classes. A second DoFHandler and FiniteElement classes must be created in order to compute the solution gradients, which are vectorial functions. Information and operations related to hull geometry is not processed here.
