Wet and Dry Transom Stern Treatment

Doctors (2003) carried out an extensive series of experiments on rectangular-section ship hulls. In these tests, the water level drop past the transom stern over a range of speeds was measured for hulls with different transom drafts.

In a further experimental investigation, Doctors et al. (2007) derived a series of algebraic formulas that correlate the dry fraction of the transom stern height \(\eta_{dry}\) to parameters related to the hull geometry and flow conditions.

In this work, we use the following regression formula:

\[ \eta_{dry} = \min(C_1\;Fr_{T}^{C_2}\;\left(\frac{B}{T}\right)^{C_3} Re_T^{C_4}, 1) \]

where \(Re_T = \sqrt{gT^3}/\nu\), \(\nu\) is the kinematic viscosity. Following Doctors, the values of the coefficients used in this work are: \([C_1,C_2, C_3, C_4]=[0.06296, 2.834, 0.1352, 0.01338]\).

We remark that in the fully nonlinear potential model that we developed, the critical value \(Fr_T^{*}\) of the transom draft Froude number is obtained from the above equation for which \(\eta_{dry} = 1\).

Pressure Patch Definition

Given the definition of \(\eta_{dry}\), the pressure \(p_R\) is computed as:

\[ p_R = \rho g (1 - \eta_{dry}) \sigma(x^*) \]

where \(\sigma(x^*)\) is a smooth function of \(x^* = x - x_{\gamma_{TS}}\), used to modulate the pressure patch and define its spatial distribution past the local longitudinal position of the transom stern \(x_{\gamma_{TS}}\).

Whenever \(\eta_{dry} = 1\), the pressure patch \(p_R\) is set to zero, and the model transitions automatically to the dry transom stern regime.

\[ \sigma(x^*) = \left(\frac{m^{HTE}}{L_{\sigma} T} - \frac{1}{L_{\sigma}^2 T}\right) {x^{*}}^2 + m^{HTE} x^* + T \]

where \(m^{HTE}\) is the hull trailing edge slope, and \(L_{\sigma}\) is the number of transom draft lengths. At \(x = 0\), \(\sigma\) equals the local transom draft \(T\), and has a slope corresponding to the hull trailing edge slope \(m^{HTE}\). The function \(\sigma(x)\) fades to zero at a specified number of transom draft lengths \(L_{\sigma}\) past the stern.
